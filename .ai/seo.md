# Purpose

SEO is a core feature of this project.

It is not an afterthought.

Every page, blog, recommendation, category and public resource must be SEO friendly.

The platform should be optimized for

• Google Search

• Google Discover

• Pinterest

• AI Search Engines

• Social Sharing

---

# SEO Philosophy

Every page should have a clear purpose.

Every page should target a search intent.

Never create duplicate pages.

Never create thin content.

Always prioritize useful content over keyword stuffing.

---

# Metadata

Every public page must generate

• Title

• Description

• Canonical URL

• Open Graph

• Twitter Card

• Robots

• Theme Color

Metadata must be dynamic.

Never hardcode metadata.

---

# URL Structure

Use readable URLs.

Good

/blog/how-to-build-a-personal-brand

/books/atomic-habits

/products/macbook-air-m4

Bad

/blog?id=123

Never expose database IDs in public URLs.

Always use slugs.
