# Purpose

This document defines the voice, tone, writing style and content strategy for the Personal Brand Platform.

Every page, blog, recommendation, button, toast, error message and section must follow these rules.

Visitors should feel like everything on the website was written by one person.

---

# Brand Personality

The brand should feel

• Warm

• Calm

• Honest

• Helpful

• Intelligent

• Modern

• Minimal

• Friendly

• Genuine

The website should never feel corporate.

The website should never feel robotic.

The website should never feel sales focused.

Trust comes before conversion.

---

# Writing Philosophy

Write for humans first.

Search engines second.

Affiliate revenue third.

Always educate before recommending.

Never recommend something just to earn commission.

---

# Voice

Speak like a mentor.

Not like a teacher.

Not like a salesperson.

Not like a marketer.

Not like an influencer.

The goal is to help people make better decisions.

---

# Tone

Conversational.

Simple.

Confident.

Respectful.

Encouraging.

Avoid exaggerated claims.

Avoid fake urgency.

Avoid clickbait.

---

# Reading Level

Content should be understandable by most readers.

Prefer simple words over complex vocabulary.

Explain technical terms when needed.

---

# Sentence Length

Prefer short and medium-length sentences.

Mix sentence lengths naturally.

Avoid long paragraphs.

Each paragraph should focus on one idea.

---

# Headings

Every heading should communicate value.

Good examples

How to Build Better Reading Habits

Books That Changed the Way I Think

Lessons I Learned From My First Website

Avoid vague titles.

Avoid keyword stuffing.

---

# Blog Structure

Every blog should include

Introduction

↓

Problem

↓

Personal Perspective

↓

Practical Advice

↓

Key Takeaways

↓

Recommended Resources

↓

Related Articles

↓

Conclusion

The structure should feel natural, not forced.

---

# Personal Stories

Share experiences honestly.

Do not exaggerate achievements.

Mention lessons learned.

Focus on helping the reader.

---

# Book Recommendations

Explain

Why the book matters.

Who should read it.

What readers can expect.

What you personally found useful.

Include affiliate links only after providing value.

---

# Product Recommendations

Recommend products only if they align with the content.

Explain

Why you recommend it.

Who it is for.

Pros.

Limitations.

Never overhype products.

---

# Affiliate Links

Be transparent.

Include a brief disclosure where appropriate.

Never pressure users to buy.

Recommendations should remain valuable even if users choose not to purchase.

---

# Calls To Action

CTAs should feel helpful.

Examples

Read the Next Article

Explore Similar Books

Discover More Resources

Share This Article

Save for Later

Avoid

Buy Now

Limited Time

Don't Miss Out

---

# Error Messages

Be clear.

Be friendly.

Avoid technical jargon.

Example

"We couldn't load this content right now. Please try again."

Never blame the user.

---

# Empty States

Explain what is happening.

Offer a next step.

Example

"You haven't saved any articles yet. Start exploring and save the ones you want to revisit."

---

# Success Messages

Keep them short.

Examples

Comment posted successfully.

Blog saved.

Changes published.

---

# Button Labels

Use clear actions.

Examples

Read Article

Save Article

Continue Reading

View Book

Explore Playlist

Avoid vague labels like

Click Here

Submit

Go

---

# About Page

Write in first person.

Focus on

Journey.

Curiosity.

Learning.

Growth.

Purpose.

Avoid sounding like a résumé.

---

# Hero Section

The hero should answer

Who are you?

What do you share?

Why should visitors stay?

Keep it concise.

---

# SEO Writing

Write naturally.

Use keywords where they fit.

Never repeat keywords unnaturally.

Always prioritize clarity.

---

# Accessibility

Avoid unnecessary jargon.

Use descriptive link text.

Write meaningful alt text.

Keep language inclusive.

---

# Grammar

Use consistent capitalization.

Avoid excessive punctuation.

Avoid ALL CAPS.

Use punctuation intentionally.

---

# AI Instructions

Before generating content,

ask

"Does this sound like a calm, helpful human?"

If the answer is no,

rewrite it.

Every piece of content should build trust.

Trust is more valuable than traffic.
